# Screenbook

Mi alternativa personal a TV Time: series y películas que veo, en qué plataforma están en España y cuántos episodios me quedan.

- **Datos de títulos y plataformas:** [TMDB](https://www.themoviedb.org/). Este producto usa la API de TMDB pero no está avalado ni certificado por TMDB.
- **Listas por persona:** Firebase (Google), con acceso solo para emails autorizados (`firestore.rules`).
- **Copia de seguridad:** botón "Descargar copia" en la web.

Es una web estática (HTML, CSS y JavaScript, sin compilación) publicada con GitHub Pages.
